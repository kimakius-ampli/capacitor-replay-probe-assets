# capacitor-replay-probe-assets

Throwaway static assets for a session-replay diagnostic probe. Public only
because the probe needs a real, publicly fetchable https origin to test
against; GitHub Pages on a private repo is auth-gated, which would have
manufactured a false "auth block" result.

Contains synthetic placeholder assets (coloured PNGs, an SVG sprite, a CSS
file, a font copied from the local system) and a static test page. No
credentials, no customer data, no personal data.
